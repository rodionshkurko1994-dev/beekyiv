# Відгуки з модерацією через Telegram

Сервіс для форми відгуків на bee.kyiv.ua. Працює на Cloudflare Workers (безкоштовний план) і зберігає відгуки в Workers KV.

Як це працює:
1. Відвідувач заповнює форму на сайті.
2. Власниця садка отримує відгук у Telegram з кнопками «✅ Опублікувати» та «❌ Відхилити».
3. Після схвалення відгук з'являється на сайті протягом хвилини.
4. Опублікований відгук можна прибрати з сайту кнопкою «🗑 Прибрати з сайту» або через команду `/list` у боті.

## Налаштування

1. **Бот.** У Telegram напишіть @BotFather, надішліть `/newbot`, задайте назву (наприклад, «Бджілка відгуки») та ім'я користувача. Збережіть токен, який видасть BotFather.
2. **Cloudflare.** Зареєструйтеся на dash.cloudflare.com.
3. **Сховище.** Storage & Databases → Workers KV → Create → назва `bee-reviews`.
4. **Worker.** Compute → Workers & Pages → Create → Worker. Назва: `bee-reviews`. Натисніть Deploy, потім Edit code, вставте вміст `worker.js` замість коду-прикладу і знову натисніть Deploy.
5. **Прив'язки.** У воркері: Settings → Bindings → Add → KV namespace. Variable name: `REVIEWS`, namespace: `bee-reviews`.
6. **Секрети.** Settings → Variables and Secrets → Add, тип **Secret**:
   - `BOT_TOKEN`: токен від BotFather;
   - `SETUP_CODE`: будь-яке слово-пароль латиницею, наприклад `med2026`;
   - `WEBHOOK_SECRET`: довгий випадковий рядок з латиниці та цифр.
7. **Підключення бота.** Відкрийте `https://<адреса-воркера>/setup?code=<SETUP_CODE>`. Сторінка покаже, яку команду надіслати боту.
8. **Власниця** відкриває бота в Telegram і надсилає `/start <SETUP_CODE>`. Відтепер відгуки надходять їй.
9. **Адресу воркера** (`https://bee-reviews.<акаунт>.workers.dev`) треба вписати в `index.html` у рядок `const REVIEWS_API`. Зараз там: `https://bee-reviews.rodionshkurko1994.workers.dev`.

Захист від спаму: приховане поле-пастка для ботів, не більше 3 відгуків на годину з однієї IP-адреси, обмеження довжини тексту. Кнопки модерації працюють лише в чаті власниці.
